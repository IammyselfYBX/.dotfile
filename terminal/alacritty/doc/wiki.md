# terminal/alacritty/doc 配置说明

> 本文档由 `dotctl` 的配置目录自动关联。
> 在 `dotctl` 中选中对应配置后按 `h` 查看本文档。

管理项：**Alacritty**

## 配置详情

### Terminal / Alacritty

Alacritty 终端配置，使用 SauceCodePro Nerd Font Mono。

- 安装方式：软链接
- 仓库源：`~/.dotfile/terminal/alacritty`
- 家目录目标：`~/.config/alacritty`

**配置组成：**

- `~/.dotfile/terminal/alacritty/alacritty.toml`
- `~/.dotfile/terminal/alacritty/README.md`

**依赖：**

- 命令 `alacritty`（必需；Arch: `alacritty`, Debian: `alacritty`）
- 字体 `SauceCodePro Nerd Font Mono`（必需）

**备注：** 字体缺失时终端仍可启动，但 Nerd Font 图标可能显示为方框。

## 使用与管理

```bash
~/.dotfile/scripts/dotctl
```

在管理器中按 `Enter` 查看详情，按 `e` 编辑源文件，按 `h` 再次打开本说明。
详细依赖目录和包名维护在 `~/.dotfile/doc/catalog.json`。
