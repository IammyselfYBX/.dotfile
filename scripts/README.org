* Dotfile manager
- =dotctl.py=: curses TUI and non-interactive CLI
- =dotctl=: executable symlink to =dotctl.py=
- =install-fonts.sh=: link shared font families
- =install-shell-entry.sh=: integrate Bash/Zsh startup files
- =install-git-include.sh=: integrate =~/.gitconfig=

Run:
#+begin_src bash
  ./dotctl
  ./dotctl --check
  ./dotctl --install-all
#+end_src


=dotctl= also manages the i3 helper commands previously installed by the
removed i3 =install.sh= scripts. Conflict items can be inspected with =d= and
overwritten with =o= after an automatic backup.


Press =e= in the list or detail page to edit the repository source file with
=$EDITOR= (fallback: =$VISUAL=, then =vim=). The curses screen is suspended and
restored when the editor exits.


Item descriptions, file groups, related entries and dependency checks are read
from =doc/catalog.json=. Startup reads that static file only; command and font
checks run when a detail page is opened.


Press =a= to show a scrollable preflight plan before running bootstrap. The plan
lists every pending item, every conflict and the action that will be performed.
