# desktop/polybar/doc 配置说明

> 本文档由 `dotctl` 的配置目录自动关联。
> 在 `dotctl` 中选中对应配置后按 `h` 查看本文档。

管理项：**Polybar**

## 配置详情

### Desktop / Polybar

Polybar 状态栏配置和启动脚本。

- 安装方式：软链接
- 仓库源：`~/.dotfile/desktop/polybar`
- 家目录目标：`~/.config/polybar`

**配置组成：**

- `~/.dotfile/desktop/polybar/config`
- `~/.dotfile/desktop/polybar/launch.sh`

**依赖：**

- 命令 `polybar`（必需；Arch: `polybar`, Debian: `polybar`）
- 命令 `i3`（必需；Arch: `i3-wm`, Debian: `i3-wm`）
- 字体 `siji`（必需）
- 字体 `unifont`（必需）

## 使用与管理

```bash
~/.dotfile/scripts/dotctl
```

在管理器中按 `Enter` 查看详情，按 `e` 编辑源文件，按 `h` 再次打开本说明。
详细依赖目录和包名维护在 `~/.dotfile/doc/catalog.json`。
