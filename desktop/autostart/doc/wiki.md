## 配置详情

### Desktop / 桌面自启动项

桌面自启动 .desktop 项。

- 安装方式：软链接
- 仓库源：`~/.dotfile/desktop/autostart`
- 家目录目标：`~/.config/autostart`

**配置组成：**

- `~/.dotfile/desktop/autostart/ignore-lid-switch-tweak.desktop`
- `~/.dotfile/desktop/autostart/msm_notifier.desktop`

**依赖：** 无额外依赖。


## 使用与管理

```bash
~/.dotfile/scripts/dotctl
```
