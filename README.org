* Dotfiles 配置仓库
本仓库统一管理个人 Linux 桌面配置。家目录中的配置文件通过软链接指向本仓库，因此直接修改家目录中的配置，实际修改的就是仓库文件。

** 安装与关联
#+begin_src bash
  git clone git@github.com:IammyselfYBX/.dotfile.git ~/.dotfile
  cd ~/.dotfile
  ./link.sh --dry-run
  ./link.sh
#+end_src

=link.sh= 会在建立链接前把已有配置备份到 =~/.dotfile-backups/<时间戳>/=。

** 同步配置
首次使用或切换电脑时先拉取：
#+begin_src bash
  cd ~/.dotfile
  git pull --ff-only
#+end_src

修改配置后提交并推送：
#+begin_src bash
  cd ~/.dotfile
  git add -A
  git commit -m "Update dotfiles"
  git push
#+end_src
