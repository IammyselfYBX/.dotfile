* Dotfiles
This repository is the source of truth for portable user configuration.
Computer-specific runtime data, caches, secrets and Vim stay outside this repo.

Vim is managed separately in =~/.vim= and is not linked or modified here.

** Layout
- =shell/=: Bash and Zsh configuration
- =terminal/=: Alacritty, WezTerm and tmux
- =desktop/=: i3, Compton, Polybar, autostart and Xorg
- =input-method/=: Rime
- =file-manager/=: Ranger
- =documents/=: Zathura and LaTeX helper configuration
- =editors/vscode/=: VS Code settings and snippets
- =git/=: shared Git configuration
- =assets/=: shared fonts, icons, wallpapers, images and themes
- =hosts/<hostname>/=: machine-specific overrides
- =packages/=: package and extension inventories
- =scripts/=: integration helpers

** First install
#+begin_src bash
  git clone git@github.com:IammyselfYBX/.dotfile.git ~/.dotfile
  cd ~/.dotfile
  ./link.sh --dry-run
  ./link.sh
  ./scripts/install-shell-entry.sh
  ./scripts/install-git-include.sh
  ./scripts/install-fonts.sh
#+end_src

=link.sh= backs up conflicting targets under =~/.dotfile-backups/<timestamp>/=.
Application directories are symlinked. Existing shell startup files are preserved
and receive a managed source block instead of being replaced.

** Shell integration
Existing =.bashrc=, =.zshrc=, =.bash_profile= and =.profile= files can remain
machine-owned. The integration script adds:
#+begin_src sh
  if [ -f "$HOME/.dotfile/shell/bashrc" ]; then
      . "$HOME/.dotfile/shell/bashrc"
  fi
#+end_src

Git uses an include block in =~/.gitconfig= so machine-specific identity settings
can coexist with =git/gitconfig=.

** Assets
Shared wallpapers and fonts live under =assets/=. i3 and WezTerm reference the
shared paths directly. Font families are linked into =~/.local/share/fonts/=
without replacing unrelated fonts.

** Host-specific settings
Host overrides live in =hosts/$(hostname -s)/=. System files such as =/etc/hosts=
are handled separately with sudo and are not symlinked from the home directory.
